# Autoencoders

This project covers the concept and implementation of **Autoencoders**, including Vanilla, Sparse, Convolutional, and Variational Autoencoders (VAEs) using Keras and TensorFlow.

## Learning Objectives

- What is an autoencoder?
- What is a latent space representation?
- What is a bottleneck?
- What is a sparse autoencoder?
- What is a convolutional autoencoder?
- What is a variational autoencoder (VAE)?
- What is Kullback-Leibler divergence?

## Tasks

| File | Description |
| --- | --- |
| `0-vanilla.py` | Creates a vanilla autoencoder |
| `1-sparse.py` | Creates a sparse autoencoder |
| `2-convolutional.py` | Creates a convolutional autoencoder |
| `3-variational.py` | Creates a variational autoencoder |

## Requirements
