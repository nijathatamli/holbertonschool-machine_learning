# Generative Adversarial Networks (GANs)

This project covers the concept and implementation of **Generative Adversarial Networks (GANs)**, including Simple GANs, Wasserstein GANs (WGAN), and WGANs with Gradient Penalty (WGAN-GP) using TensorFlow and Keras.

## Learning Objectives

- What is a Generative Adversarial Network (GAN)?
- What is the Generator and Discriminator?
- What is the minimax game loss function?
- What is Mode Collapse and how to mitigate it?
- What is Wasserstein GAN (WGAN) and Earth Mover's Distance?
- What is Gradient Penalty in WGAN-GP?

## Tasks

| File | Description |
| --- | --- |
| `0-simple_gan.py` | Implementation of a Simple GAN |
| `1-wgan.py` | Implementation of a Wasserstein GAN (WGAN) |
| `2-wgan_gp.py` | Implementation of WGAN with Gradient Penalty (WGAN-GP) |
| `3-generate_faces.py` | Generates synthetic faces using trained GAN |
