# Recurrent Neural Networks (RNNs)

This project covers the implementation and architecture of **Recurrent Neural Networks (RNNs)**, including RNN Cells, LSTM Cells, GRU Cells, Deep RNNs, and Bidirectional RNNs built from scratch using NumPy.

## Learning Objectives

- What is a Recurrent Neural Network (RNN)?
- What is a cell?
- What is a hidden state?
- What is a gated recurrent unit (GRU)?
- What is long short-term memory (LSTM)?
- What is a bidirectional RNN?
- What is a deep RNN?
- What is backpropagation through time (BPTT)?

## Tasks

| File | Description |
| --- | --- |
| `0-rnn_cell.py` | Class `RNNCell` that represents a simple RNN cell |
| `1-rnn.py` | Performs forward propagation for a simple RNN |
| `2-gru_cell.py` | Class `GRUCell` that represents a Gated Recurrent Unit |
| `3-lstm_cell.py` | Class `LSTMCell` that represents an LSTM cell |
| `4-deep_rnn.py` | Performs forward propagation for a Deep RNN |
| `5-bi_forward.py` | Bidirectional RNN cell forward step |
| `6-bi_backward.py` | Bidirectional RNN cell backward step |
| `7-bi_output.py` | Bidirectional RNN outputs computation |
| `8-bi_rnn.py` | Performs forward propagation for a Bidirectional RNN |

## Requirements

- Allowed editors: `vi`, `vim`, `emacs`

- All files must be executable (`chmod +x`)
