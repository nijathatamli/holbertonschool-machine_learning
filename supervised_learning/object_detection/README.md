# Object Detection - YOLOv3

This directory contains tasks and implementations related to Object Detection algorithms, specifically focusing on **YOLOv3** (You Only Look Once).

## Tasks

| File | Description |
| --- | --- |
| `0-yolo.py` | Initializes the `Yolo` class with the model, class names, thresholds, and anchor boxes. |

## Requirements

- Python 3.8+
- TensorFlow 2.x / Keras
- NumPy
- OpenCV
- `pycodestyle` compliance
