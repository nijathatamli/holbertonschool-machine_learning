# Natural Language Processing - Evaluation Metrics

This directory contains implementations of various Natural Language Processing (NLP) evaluation metrics used to measure model performance in tasks like Machine Translation, Text Summarization, and Language Modeling.

## Learning Objectives

- What is the BLEU score and how is it calculated?
- What is the ROUGE score and how does it evaluate text summarization?
- What is Perplexity and how does it measure language model accuracy?
- What are the strengths and shortcomings of various NLP evaluation metrics?

## Files

| File | Description |
| --- | --- |
| `0-uni_bleu.py` | Calculates the unigram BLEU score for a sentence |
| `README.md` | Overview and documentation for the NLP Evaluation Metrics module |

## Requirements

- Allowed editors: `vi`, `vim`, `emacs`

- Code must adhere to `pycodestyle` style guidelines (version 2.8.x)
- All files must be executable (`chmod +x`)
