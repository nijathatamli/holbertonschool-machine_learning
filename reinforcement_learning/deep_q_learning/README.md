# Reinforcement Learning - Deep Q-Learning (DQN)

This directory contains implementations of Deep Q-Learning algorithms applied to OpenAI Gym environments (e.g., Atari Breakout).

## Learning Objectives

- What is Deep Q-Learning (DQN)?
- How to combine Q-Learning with Deep Neural Networks
- Understanding Experience Replay and Target Networks
- Training a DQN agent using `keras-rl2` / `keras` and OpenAI Gym
- Evaluating and playing trained RL models

## Files

| File | Description |
| --- | --- |
| `train.py` | Python script to train a Deep Q-learning agent on Breakout and save the policy weights |
| `play.py` | Python script to display a game played by the trained agent |
| `README.md` | Documentation for the Deep Q-Learning module |

## Requirements

- Ubuntu 20.04 LTS with Python 3.8
- `pycodestyle` style guidelines (version 2.8.x)
- All files must be executable (`chmod +x`)
- Code must follow POSIX standard (end with a new line)
